# 🌍 Projeto Travis Scott — Utopia World

Site temático desenvolvido com foco no álbum **"Utopia"** do artista norte-americano **Travis Scott**.  
O projeto reúne conteúdos visuais, vídeos e páginas dedicadas à experiência imersiva do álbum.

🔗 **Acesse o site:** [rafaeldegino.github.io/Utopia-World](https://rafaeldegino.github.io/Utopia-World/)

---

## 🎯 Objetivo

Criar uma experiência interativa e visual inspirada na estética do álbum **Utopia**, explorando conceitos de design, navegação e multimídia na web.

---

## 🧰 Tecnologias e Destaques
✅ HTML5 e CSS3 para estrutura e estilo

✅ Navegação temática e estilizada

✅ Uso de JavaScript básico para interações simples

✅ Páginas exclusivas para seções como turnê e vídeos

✅ Integração de conteúdo audiovisual (vídeos e imagens)

✅ Estética baseada na identidade visual do álbum Utopia
